# OARP — Observable Agentic RAG Platform

An experimental platform for **building, evaluating, and optimizing AI agents**, with a focus on agentic RAG, harness optimization, and observability.

The project explores how agent configurations, tool usage, and execution strategies affect task success, reliability, latency, and cost.

### Planned features
- Modular AI agents with configurable tools and execution policies
- Reproducible evaluation and benchmarking
- Agent harness optimization through controlled experiments
- Hybrid retrieval (BM25 + vector search) and reranking
- End-to-end tracing and observability

### Status

🚧 **Early development** — Starting with a coding-agent MVP and evaluation framework, with plans to extend the platform to RAG applications.
